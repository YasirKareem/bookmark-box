# Support — Bookmark Box

## Reporting a bug

Open an issue in this repository:
**https://github.com/YasirKareem/bookmark-box/issues**

### What to include

A useful bug report has three things:

1. **Environment**
   - Firefox version (find it at `about:support` → Application Basics → Version)
   - Extension version (find it at `about:addons` → Bookmark Box → Version)
   - Operating system (Windows / macOS / Linux)

2. **Steps to reproduce**
   - A numbered list of exactly what you did before the problem occurred
   - The more specific, the faster it can be reproduced

3. **What happened vs. what you expected**
   - What the extension did
   - What you expected it to do

**Optional but helpful:**

- Console errors — open the browser console with `Ctrl+Shift+J` (Windows/Linux) or `Cmd+Option+J` (macOS), reproduce the problem, and paste any red error lines into the issue

---

## Asking a question

Open a GitHub issue and prefix the title with `[Question]:`. There is no separate forum or discussion board.

---

## Known limitations

- Preview thumbnails require the `<all_urls>` optional permission. Firefox will prompt you the first time you use Preview Capture or Broken-Link Check.
- Some websites block automated requests, which may cause false positives in the Broken-Link scanner.
- The extension is Firefox-only. It is not compatible with Chrome or other Chromium-based browsers.
